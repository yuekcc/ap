# 11. 浏览器界面 ap-web

`ap-web` 把 ap 放进浏览器。它不实现 agent，每个用户 turn 启动一个 `ap` 子进程，通过 HTTP API 和 SSE 把事件转发给页面。前端资源在编译期内置进单个可执行文件，不需要额外分发静态文件。

## 启动与访问

```sh
./build/ap-web
```

默认地址：

```text
http://127.0.0.1:8417
```

常用参数：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `--port <n>` | `8417` | 监听端口，范围 1 到 65535 |
| `--host <addr>` | `127.0.0.1` | 监听地址。显式监听非回环地址会打印安全警告 |
| `--cwd <dir>` | 启动目录 | 初始工作目录，同时作为默认项目 |
| `--agent-bin <path>` | 空 | 指定 `ap` 可执行文件 |
| `--config-dir <dir>` | `~/.ap` | 传给 `ap` 的配置目录 |
| `--model <id>` | 空 | 传给 `ap --model` |
| `--agent <name>` | 空 | 传给 `ap --agent` |
| `--max-steps <n>` | 空 | 传给 `ap --max-steps` |
| `--max-tokens <n>` | 空 | 传给 `ap --max-tokens` |
| `--web-root <dir>` | 空 | 静态资源改从磁盘读取，开发时用 |
| `-c`, `--continue` | 关 | 恢复当前项目最近的根会话 |
| `-s`, `--session <id>` | 空 | 恢复指定会话 |

`-s` 和 `-c` 互斥。`ap-web` 不暴露 `--no-agents-md` 和 `--no-skills`，它拉起的 `ap` 使用默认上下文。

## 页面怎么用

- **顶部工作空间标签**：每个标签对应一个目录。点「+」选择目录，在该目录开新工作空间。
- **左栏**：当前工作空间的「开启新对话」按钮和对话记录。记录按今天、昨天、前天、更早分组。
- **右栏**：当前会话的标题、消息区和输入框。
- **消息区**：用户消息是蓝色气泡，assistant 文本按 Markdown 渲染，工具调用显示为可折叠卡片。
  卡片默认收起，只留一行关键信息（工具名、参数、耗时、退出码），点这一行才展开流式输出和结果。
- **思考中**：模型还没吐出可见文本时，消息区末尾居中显示呼吸点动画；文本或工具执行一开始就收起。
- **标题**：顶栏显示当前会话的标题。首轮跑完后自动生成一次（生成期间状态仍是「运行中」），标题旁的刷新按钮可以再生成一次。
- **输入框**：发送、取消、显示当前工作空间路径；placeholder 里带 Enter / Shift+Enter 键位提示。
- **交接**：输入框下方的「交接」按钮生成交接文档并创建新会话；输入框里的文字作为交接后的首个提示词。
- **token 用量**：工作区顶栏（模型、agent 旁边）显示当前会话的累计 token，悬停可看输入、输出、缓存与推理明细。
- **顶栏右侧**：在当前工作目录打开文件管理器或终端。

打开已有会话时，页面先恢复运行态，再读取历史，最后订阅事件。刷新后能从 transcript 重放历史。

## 新建与恢复

- 新对话：在当前工作空间开一个空会话，第一轮提示词发出后才落盘。
- 历史对话：点左栏的条目恢复。
- 切换工作空间：打开该目录最近一条会话；没有记录就在该目录新建。
- 刷新：当前标签页把 `{key, id, cwd}` 存在 `sessionStorage`，刷新时优先按真实 id 和目录恢复。

## 手动交接

输入框下方的「交接」等价于 CLI 的 `ap -s <id> --handoff`：

- 输入框有文字时，这段文字既是交接的聚焦提示，也是新会话的第一个 turn。
- 输入框为空时只生成交接文档并创建新会话，不跑 turn。
- 当前会话至少要跑过一轮（ap 需要真实的 session id）；新 slot 会被禁用并提示无法交接。
- 聚焦提示词上限 8KB：它作为 `--handoff=<文本>` 走命令行，不像普通提示词那样走 stdin。

交接完成后服务端会推送新会话的 `session_start`，当前标签页自动切到新会话并重放它的 transcript；源会话仍留在侧栏。上下文快满时的自动交接走同一条路径，页面也会跟着切换。

## 会话标题

侧栏每个会话显示两行：标题与元信息（短 id · 轮数）。标题来自 transcript 的 `session_title` 事件，最后一条生效；还没生成过时退回 id 里的日期时间。

- 自动生成：首轮正常结束（`turn_end.stop_reason` 为 `stop`）后，ap-web 在同一个 turn 线程里再起一个 `ap -s <id> --session-title`，因此这个 session 会多显示几秒「运行中」。失败只在 stderr 留一行日志，不影响本轮结果。
- 人工刷新：标题旁的刷新按钮等价于同一条命令，正在跑 turn 或已经在生成时返回 409（按钮此时禁用）。
- 标题进程与 turn 共用该 session 的分飞锁，不会同时写 transcript。
- 前端收到 SSE 的 `session_title` 事件后同时更新顶栏与侧栏条目；刷新接口也直接返回最终标题。

## token 用量

工作区顶栏显示当前会话的累计 token。数据来自 `turn_end.usage` 与 `session_end.usage`：前者按轮累加，后者是整份 transcript 的累计值、会覆盖前者，所以刷新后从 history 重放也能还原。

## 取消

页面提供单轮取消。服务端收到取消后终止对应的 `ap` 进程树。

- 同一会话同一时刻只允许一个 turn，重复发送会返回 409。
- 不同会话可以并发。
- 浏览器断开 SSE 不会自动取消 turn。
- Windows 上取消是整树强制终止，transcript 可能停在 `tool_execution_start`。页面会合成 `cancelled` 状态，刷新后仍能重放已经落盘的部分。

## 选择工作目录

Windows 上点顶部「+」会打开系统目录选择框。Unix 目前没有统一的原生目录对话框，接口返回 501，页面会提示当前平台不支持。

目录选择只返回路径，不修改服务端进程的工作目录。随后前端在该目录开新 slot。

## 打开工作目录

顶栏右侧有两个按钮，在当前工作目录（当前工作空间的 `cwd`）打开外部程序：

| 按钮 | Windows | macOS | Linux |
| --- | --- | --- | --- |
| 文件管理器 | `explorer <cwd>` | `open <cwd>` | `xdg-open <cwd>` |
| 终端 | `wt.exe -d <cwd>` | `open -a Terminal <cwd>` | 依次尝试 `x-terminal-emulator`、`gnome-terminal`、`konsole`、`xfce4-terminal`、`kitty`、`alacritty`、`xterm` |

对应 `POST /api/cwd/reveal` 和 `POST /api/cwd/terminal`，请求体可选 `{"cwd": "<dir>"}`，缺省用默认 project。程序由 ap-web 在本机拉起，子进程的 working dir 就是该目录；接口只返回 `{cwd}`，不改变 cwd、project 或任何 session 的运行态。

启动失败（例如 Windows 上没有 Windows Terminal，或 Linux 上找不到终端模拟器）返回 500 `open_failed`，页面把它落成一条 notice。

## 安全前提

1. 默认只监听 `127.0.0.1`。显式监听其他地址时，启动日志会打印警告。
2. 没有登录鉴权。能访问端口的人就能使用 shell。
3. 不提供 HTTPS。需要外网或多用户时，由外部反向代理承担 TLS 和访问控制。
4. 请求体有上限，提示词上限 1 MiB、交接的聚焦提示词上限 8 KB，但这不构成权限边界。

不要把 `--host 0.0.0.0` 直接暴露到不可信网络。先读 [第 15 章](15-safety.md)。

## 已知限制

- 不支持 `Last-Event-ID` 断点续传。断线重连后页面重新读 history，再按 `seq` 去重。
- 不支持 session fork、session 删除和文件附件上传。
- 不显示 reasoning 文本，只在等待模型输出时给出「思考中」动画。
- token 只显示当前会话的累计值，不按轮拆分，也不换算金额。
- 只提供浅色主题。
- 前端目标浏览器是 Chrome 110、Edge 110、Firefox 110、Safari 16。没有 polyfill。

需要开发前端时，用 `--web-root ap-web/dist` 从磁盘读取资源，改完刷新页面即可。正式使用时用内置资源，不需要带 `dist` 目录。

图标来自 `bootstrap-icons`：`index.html` 只写 `<svg data-icon="名字">` 占位，构建时把 SVG 内联进去，页面不会额外请求图标字体或 sprite。
