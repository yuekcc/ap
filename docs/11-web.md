# 11. 浏览器界面 ap-web

`ap-web` 把 ap 放进浏览器。它不实现 agent，每个用户 turn 启动一个 `ap` 子进程，通过 HTTP API 和 SSE 把事件转发给页面。前端资源在编译期内置进单个可执行文件，不需要额外分发静态文件。

## 启动与访问

```sh
./build/ap-web
```

默认地址：

```text
http://127.0.0.1:8417
```

常用参数：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `--port <n>` | `8417` | 监听端口，范围 1 到 65535 |
| `--host <addr>` | `127.0.0.1` | 监听地址。显式监听非回环地址会打印安全警告 |
| `--cwd <dir>` | 启动目录 | 初始工作目录，同时作为默认项目 |
| `--agent-bin <path>` | 空 | 指定 `ap` 可执行文件 |
| `--config-dir <dir>` | `~/.ap` | 传给 `ap` 的配置目录 |
| `--model <id>` | 空 | 传给 `ap --model` |
| `--agent <name>` | 空 | 传给 `ap --agent` |
| `--max-steps <n>` | 空 | 传给 `ap --max-steps` |
| `--max-tokens <n>` | 空 | 传给 `ap --max-tokens` |
| `--web-root <dir>` | 空 | 静态资源改从磁盘读取，开发时用 |
| `-c`, `--continue` | 关 | 恢复当前项目最近的根会话 |
| `-s`, `--session <id>` | 空 | 恢复指定会话 |

`-s` 和 `-c` 互斥。`ap-web` 不暴露 `--no-agents-md` 和 `--no-skills`，它拉起的 `ap` 使用默认上下文。

## 页面怎么用

- **顶部工作空间标签**：每个标签对应一个目录。点「+」选择目录，在该目录开新工作空间。
- **左栏**：当前工作空间的「开启新对话」按钮和对话记录。记录按今天、昨天、前天、更早分组。
- **右栏**：当前会话的标题、消息区和输入框。
- **消息区**：用户消息是蓝色气泡，assistant 文本按 Markdown 渲染，工具调用显示为卡片。
- **输入框**：发送、取消、显示当前工作空间路径。

打开已有会话时，页面先恢复运行态，再读取历史，最后订阅事件。刷新后能从 transcript 重放历史。

## 新建与恢复

- 新对话：在当前工作空间开一个空会话，第一轮提示词发出后才落盘。
- 历史对话：点左栏的条目恢复。
- 切换工作空间：打开该目录最近一条会话；没有记录就在该目录新建。
- 刷新：当前标签页把 `{key, id, cwd}` 存在 `sessionStorage`，刷新时优先按真实 id 和目录恢复。

## 取消

页面提供单轮取消。服务端收到取消后终止对应的 `ap` 进程树。

- 同一会话同一时刻只允许一个 turn，重复发送会返回 409。
- 不同会话可以并发。
- 浏览器断开 SSE 不会自动取消 turn。
- Windows 上取消是整树强制终止，transcript 可能停在 `tool_execution_start`。页面会合成 `cancelled` 状态，刷新后仍能重放已经落盘的部分。

## 选择工作目录

Windows 上点顶部「+」会打开系统目录选择框。Unix 目前没有统一的原生目录对话框，接口返回 501，页面会提示当前平台不支持。

目录选择只返回路径，不修改服务端进程的工作目录。随后前端在该目录开新 slot。

## 安全前提

1. 默认只监听 `127.0.0.1`。显式监听其他地址时，启动日志会打印警告。
2. 没有登录鉴权。能访问端口的人就能使用 shell。
3. 不提供 HTTPS。需要外网或多用户时，由外部反向代理承担 TLS 和访问控制。
4. 请求体有上限，提示词上限 1 MiB，但这不构成权限边界。

不要把 `--host 0.0.0.0` 直接暴露到不可信网络。先读 [第 15 章](15-safety.md)。

## 已知限制

- 不支持 `Last-Event-ID` 断点续传。断线重连后页面重新读 history，再按 `seq` 去重。
- 不支持 session fork、session 删除和文件附件上传。
- 不显示 reasoning，也没有 usage 状态条。
- 只提供浅色主题。
- 前端目标浏览器是 Chrome 110、Edge 110、Firefox 110、Safari 16。没有 polyfill。

需要开发前端时，用 `--web-root ap-web/dist` 从磁盘读取资源，改完刷新页面即可。正式使用时用内置资源，不需要带 `dist` 目录。
